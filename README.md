## Engineering principles

1. **Evidence before claims.** Sources, assumptions, calculations, and limitations should be inspectable.
2. **Accessibility from the first commit.** Screen-reader support, keyboard access, plain language, and bilingual design are core requirements.
3. **Human judgment remains accountable.** Automated systems should support decisions without hiding responsibility.
4. **Real-world constraints matter.** Systems should remain useful with limited bandwidth, older hardware, and interrupted connectivity.
5. **Privacy is architecture.** Collect the minimum data necessary and keep sensitive work local whenever possible.
