# Security and Privacy Policy

This repository is public. Never submit veteran medical records, claim files, VA file numbers, Social Security numbers, complete birth dates, home addresses, signatures, passwords, API keys, authentication tokens, private correspondence, proprietary Ayala material, or patent-sensitive disclosures.

For observatory-specific controls, see [`observatory/SECURITY.md`](observatory/SECURITY.md).

Use GitHub private vulnerability reporting when enabled for a vulnerability that cannot be safely disclosed in a public issue. Data corrections and accessibility defects should use the structured issue templates and must not contain protected personal information.
