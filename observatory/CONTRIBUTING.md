# Contributing

Contributions are welcome when they improve factual accuracy, reproducibility, accessibility, Spanish-language quality, or software reliability.

## Required structure for a data correction

1. Identify the exact disputed statement or metric.
2. Provide an authoritative source URL.
3. Identify the page, table, row, or reporting date.
4. Explain the proposed correction.
5. State whether the correction changes a downstream calculation.

## Quantitative contributions

- Preserve the four evidence classifications: Official, Calculated, Scenario, and Unknown.
- Do not convert a scenario into a factual claim.
- Include unit definitions and denominators.
- Add source date, retrieval date, limitation, and checksum when applicable.
- Add or update a reproducible test for any formula change.

## Accessibility contributions

Do not remove semantic headings, landmarks, table captions, label associations, keyboard support, visible focus, text alternatives, or reduced-motion behavior. Automated test results do not replace manual screen-reader review.

## Prohibited content

Never submit personal veteran records, credentials, medical information, proprietary Ayala logic, or patent-sensitive material.
