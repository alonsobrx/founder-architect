# Security and Privacy Policy

This public repository must never receive individual veteran claim files, medical records, VA file numbers, Social Security numbers, complete birth dates, home addresses, signatures, passwords, API keys, authentication tokens, private correspondence, or proprietary Ayala material.

## Reporting a software vulnerability

Open a GitHub issue only when the report can be made without disclosing an exploitable secret or personal information. For a sensitive security report, use GitHub's private vulnerability-reporting feature when enabled.

## Data corrections are not security reports

Use a normal issue and identify the disputed statement, authoritative source, exact page or table, and requested correction. Do not attach protected personal records.
